# 監査サンプリング設計ツール

監査リスクの評価からサンプル数の算定、誤謬評価、監査調書の出力までをブラウザ上で支援する、単一HTMLファイルのツールです。

J-SOX関連ツール群で統一して利用できるよう、[J-SOX Flow Builder](https://github.com/norimaki-audit/jsox-flow-builder) と共通のデザイン言語を採用しています。

## 主な機能

- 監査リスクモデル（AR・IR・CR）の計算
- 統制テストのサンプル数設計
- BS項目のPPS/MUSサンプリング
- PL項目の実証サンプリング
- 非統計的サンプリングの判断支援
- 統制逸脱・実証手続の誤謬評価
- サンプル数早見表
- 計算結果のコピーと監査調書出力
- デスクトップ・モバイル対応

## 使い方

1. リポジトリをダウンロードまたはクローンします。
2. `index.html` をブラウザで開きます。
3. 監査対象情報とリスク評価、母集団情報を入力します。
4. 計算結果を確認し、必要に応じてコピーまたは調書出力を実行します。

ビルドやインストールは不要です。

## データの取扱い

このツールの計算処理はブラウザ内で完結します。

- 入力した会社名、勘定科目、金額、サンプリング結果をサーバーへ送信する処理はありません。
- `fetch`、`XMLHttpRequest`、WebSocket、アクセス解析、テレメトリーは使用していません。
- `localStorage` に保存するのは表示倍率（`auditToolZoom`）だけです。
- 入力した監査データはリポジトリへ自動保存されません。
- コピーや調書出力を実行した場合、データは利用者のクリップボードまたは端末上のファイルとして扱われます。

### 外部通信

画面表示のため、次の公開CDNからフォントとアイコンを読み込みます。

- Google Fonts: `fonts.googleapis.com`、`fonts.gstatic.com`
- Phosphor Icons: `unpkg.com`

これらのリクエストに入力フォームの値を含める実装はありません。ただし、CDN側には一般的なWebアクセスと同様にIPアドレスやUser-Agentなどの通信情報が伝わる可能性があります。完全なオフライン環境で使用する場合は、外部リソースを組織内でホストするか、システムフォントへ置き換えてください。

## 注意事項

本ツールは監査サンプリング設計を補助するものであり、監査基準への準拠や監査判断の妥当性を保証するものではありません。最終的な判断は、適用される監査基準、組織の方針、監査人の職業的専門家としての判断に基づいて行ってください。
